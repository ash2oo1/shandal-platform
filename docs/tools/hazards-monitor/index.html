Natural Hazards Monitor

Earthquakes, fires, storms and volcanoes, live on one map.

Combines real-time feeds from USGS and EMSC for earthquakes, NASA EONET for wildfires, storms, floods, dust and volcanoes, GDACS disaster alerts and, with a free key, NASA FIRMS active-fire detections.

Overview

Switch each feed on or off, set the time window and minimum magnitude, and see events sorted by time or by distance from you. Selecting an event opens its source record. Events export as GeoJSON for use in GIS.

What you enter · What you get

What you enter

  • Feeds to show
  • Time window and minimum magnitude
  • FIRMS map key (optional)

What you get

  • Live event map
  • Event list by time or distance
  • Counts per feed
  • GeoJSON export

Method and equations

Sources

USGS real-time GeoJSON feeds; EMSC FDSN event service; NASA EONET v3; GDACS event API; NASA FIRMS area API (VIIRS 375 m).

Who uses it

Civil defence and emergency teamsField-team leadersResearchers and journalists

Standards and references

  1. U.S. Geological Survey, Earthquake Hazards Program real-time feeds.
  2. European-Mediterranean Seismological Centre (EMSC), seismicportal.eu.
  3. NASA Earth Observatory Natural Event Tracker (EONET) v3.
  4. Global Disaster Alert and Coordination System (GDACS), European Commission JRC.
  5. NASA Fire Information for Resource Management System (FIRMS).
Results support professional judgement. They do not replace a licensed engineer’s or geologist’s sign-off.
